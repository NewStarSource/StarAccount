# 账户资料与恢复保护交付

本次依据 S07 交接和 2026-09-26 执行报告补齐账户与星图的实际边界。当前为回环 development/test 环境，未开放真实用户，未进行图形浏览器复现。

## 公开资料及身份接口

资料编辑表单回填 display_name、bio、location 和 website；长度按 Unicode 字符检查，个人网站仅接受有主机名且不含凭据的 HTTP/HTTPS 地址。星图通过带客户端认证的 `/internal/identity/profile` 读取公开字段白名单，不读取账户库、密码、用户名或邮箱。

`/internal/identity/deactivate` 要求已认证星图客户端、正确用户和会话对应关系、五分钟内重新认证，以及尚未撤销的有效账户会话。状态、恢复期限与会话撤销在一个事务中保存；恢复通过账户服务校验凭据，不恢复旧会话。

## 独立清单与普通快照

schema 5 记录凭据变化。身份状态、会话撤销和凭据变更的最小事件进入独立 HMAC 链及逐条锚点，POST 成功响应之前写入清单。清单不包含密码、令牌、邮件正文或个人资料。服务启动时检查清单并重放旧库缺少的撤销事件。

普通快照使用独立备份密钥和 AES-GCM，验证哈希、schema 与清单水位；不包含会话、授权请求、OIDC token 或邮件 token。小时快照保留 48 小时，每日保留 30 天，每月保留 12 个月。过期注销账户的旧归档也清除凭据和个人资料。

恢复命令只允许尚不存在的新目标路径，使用最新独立清单、锚点和配置密钥，清除旧会话与授权材料。快照之后发生密码变化的账户进入 recovery_pending 并清空旧哈希，避免旧密码重新生效；该状态需要后续受控身份恢复，不能直接重新开放登录。

## 验证与操作

账户全量 Go 测试、vet 与 govulncheck 通过；原始 HTTP 联调覆盖实际邀请码注册、PKCE 登录、资料回填、注销恢复、身份服务故障和撤销。自动化合成备份/恢复、清单截断和归档损坏检查均使用临时目录。

在 AtlasSite 执行 `pwsh -File scripts/check_core.ps1` 可验证两个仓库。账户 CLI 提供 `backup`、`diagnose`、`restore`；具体配置、独立文件保护与隔离恢复见 [跨服务运行手册](../../AtlasSite/docs/RUNBOOK_CORE.md)。

本地默认独立文件仍位于同一磁盘，没有配置离机副本、正式服务账户权限、真实域名/HTTPS、实际外部告警或定期巡检任务。独立 AI 审核及邀请观察的发布条件见 [核心交付记录](../../AtlasSite/docs/CORE_GAPS_2026-10-06.md)。
