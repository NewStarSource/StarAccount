# 2026 年 11 月开发记录

## 11 月 1 日

### 第一批改动

安全页增加修改密码入口，页面为 `/security/password`，提交到 `/api/v1/security/change-password`。用户验证当前密码并确认新密码后，服务在同一事务中更新密码、撤销本人全部旧会话、删除旧恢复码与相关临时凭据。

提交时复查原密码摘要、当前会话、有效期及账户状态，避免并发找回、改密或撤销覆盖新凭据。复用已有凭据变更事件和独立安全记录，不新增数据库迁移。账户数据库版本仍为 6。

表单使用现有样式，关闭 JavaScript 仍可提交。输入失败时在原表单显示错误，密码不回填。成功后清除当前会话 Cookie，提示重新登录并生成新恢复码。

### 验证

两端完整 Go 测试、vet、构建和既有 JavaScript 交互回归已通过。改密定向测试覆盖错误输入、CSRF、会话过期和撤销、账户停用、限流、并发冲突、事务失败回滚及备份不复活旧密码。

真实双服务 HTTP 联调由 AtlasSite 的 `scripts/test_core.py` 扩展，使用临时合成数据库，已通过改密后账户和星图会话同时失效、旧密码和旧恢复码被拒绝、新密码可以重新登录的检查。原有发布、管理台、注销恢复、加密备份与告警去重回归，以及 `scripts/test_s03.py` 的 OIDC 安全回归同样通过。补充测试确认其他账户的密码和会话不受影响。

本轮未进行图形浏览器视觉复查，未部署或重启服务器服务。

### 第二批改动

安全页整理为密码、恢复码、有效会话三个入口。当前会话始终排在列表最前，显示登录时间与到期时间，过期及撤销会话不列出。保留最多 100 条展示，同时显示有效会话总数，超过上限时说明退出全部会话也处理未列出的会话。

恢复码页面增加未设置、可用、已过期三种状态，显示生成时间和有效期。查询只读取本人恢复码的时间信息，不读取摘要或重复显示明文。生成与替换继续验证当前密码，输入错误及限流在原表单提示，密码不回填。

原生表单确认身份后返回安全页，页面显示五分钟确认期。退出其他会话后刷新列表，退出当前或全部会话后说明重新登录。注销、找回密码、注销恢复和灾难恢复帮助放进可展开区域。没有新增 JavaScript 依赖或数据库迁移。
