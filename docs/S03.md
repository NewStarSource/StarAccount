# S03 本地身份服务

完整交付清单位于相邻 `AtlasSite/docs/S03.md`，协议约定位于 `AtlasSite/docs/identity-contract.md`，审核记录位于 `AtlasSite/docs/review-S03.md`。

账户新增 `/oidc/login`、`/security`、`/recover`、`/api/v1/auth/sessions` 和 `/api/v1/security/{reauthenticate,revoke,revoke-all,deactivate,restore}`。安全操作使用同源 CSRF 表单；恢复只在 30 天窗口内重新验证密码后执行。

内部事件和会话状态查询只允许固定客户端 Basic Auth；Cookie 不授权内部 API。本地只有一个星图客户端、一个 RS256 签名密钥，精确回调白名单；刷新令牌、设备流、JWT Profile、Token Exchange、公开管理路由均关闭。

运行 `go run ./cmd/staraccount init-oidc` 初始化本地签名密钥与客户端配置，密钥不打印。星图随后执行其 `init-oidc`。进程升级前停止旧服务并保存合成库备份，002 迁移不自动降级。

真实 SMTP、HTTPS、公开域名、生产管理额外验证以及内容删除/匿名化均未验收。
